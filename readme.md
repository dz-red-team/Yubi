Yubi - open-source ПО для Windows

![image](assets/image.jpg)

Принцип работы программы заключается в помощи пользователю с навигацией по системе при помощи строки ввода команд. Пользователь заранее создаёт сценарии (пример: быстро открыть FL Studio.exe) и назначает им быструю команду (пример: "fl" ). Пользователь может создавать дополнительные условия для команд (пример: "fl 20" или "fl 21", чтобы открыть соответственно разные версии одной и той же программы).

Создание сценариев в программе реализовано при помощи визуального построения последовательности и условий логическими блоками, при этом в программе есть шаблоны сценариев, например для взаимодействия с WEB (пример: поиск через =text+text+text).

Cтрока ввода команд открывается сочетанием клавиш, выбранным пользователем. Она открывается не отдельным окном, а оверлеем поверх всех программ. У строки есть список последних использованных команд, при вводе команд пользователю показываются подсказки.
